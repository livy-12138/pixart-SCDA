## 一、最重要的发现：交叉注意力掩码被关闭（ISSUE-011）

### 问题

`diffusion/model/nets/PixArt_blocks.py` 的 `MultiHeadCrossAttention` 被改写时加入了
SDPA 回退分支，其中：

```python
if isinstance(mask, (list, tuple)):
    key_padding = None          # ← 掩码被丢弃
```

而 `PixArt.forward` 传下去的恰恰是 **list**（`y_lens = mask.sum(dim=1).tolist()`）。
结果：**所有图像 Patch 都在注意 T5 的 padding token**。

### 为什么之前没暴露

T5 序列固定补零到 120。`asset/samples.txt` 的提示词很长（padding 少）→ 影响小；
benchmark 的短提示词（110+/120 是 padding）→ 灾难性退化。

### 定位证据链

| 对照 | 结果 |
|---|---|
| diffusers 原生管线加载同一权重 | **正常出图** |
| 逐张量比对 checkpoint 与 HF 权重 | **完全相同（maxdiff = 0）** |
| fp16 vs fp32 | 输出一致，都退化 |
| `git diff --ignore-cr-at-eol` | 锁定到 `PixArt_blocks.py` |
| 运行时补丁恢复掩码 | **恢复正常出图** |

### 影响

| 类别 | 当前代码 | 恢复掩码 | 公开 PixArt-α |
|---|---:|---:|---:|
| 颜色 | 0.1754 | **0.3922** | 0.6690 |
| 2D空间 | 0.0000 | **0.1969** | 0.2064 |
| 计数 | 0.0346 | **0.4961** | 0.5058 |

**论文表2/表3/表4 与 4.3.1—4.3.3 节的全部数值都是在退化图像上算的。**

### 处置

已修复 `PixArt_blocks.py`（新增 `cross_attn_key_padding()`），并验证修复后的代码
与运行时补丁**逐位一致**（20/20），因此表5 数据依然成立。

## 三、第二个发现：可学习层门控从未学习（ISSUE-008 / ISSUE-013）

### 现象

14 786 步训练后，28 层的门控与初始化值最大偏差只有 **1.6e-04**，层间标准差 ~1e-5。
即：**门控没有形成任何层间差异**。

### 根因（已量化）

初始化 `±4.0` 把参数放进了 sigmoid 的**饱和区**，`dλ/dw = λ(1−λ)` 只有 **0.0177**
（λ=0.5 时是 0.25）。关键不等式：

```
最大可变距离 = 学习率 3.536e-6 × 14 786 步 ≈ 0.052
需要走的距离 = ~1.0（才能离开饱和区）
差 20 倍；按实测位移 0.0092 算差 100 倍
```

**即：在那个学习率下，无论训练多久门控都不可能离开初始化点。**

对照实验（同一 checkpoint、同一数据、同 lr、150 步，只改初始化）：

| 变体 | \|Δλ\| 最大 | \|Δw\| 最大 |
|---|---:|---:|
| A 当前初始化 w=±4 | 9.89e−06 | 5.58e−04 |
| B 预热初始化 w=±1 | **1.06e−04（10.7×）** | 5.39e−04 |
| C 去正则 | 9.96e−06（1.0×） | 5.64e−04 |

`|Δw|` 几乎相同 → 差异**完全来自饱和区**，与梯度路径、正则无关。

### 已实施的改造（全部带日志）

| 改动 | 效果 |
|---|---|
| 初始化 ±4 → **±1** | dλ/dw 从 0.018 → 0.21 |
| 两级压缩合并为**一个**可学习标量 | 原来有效强度只有 `0.0164 × 0.018 ≈ 3e-4` |
| 注入上限 **warmup 0 → 0.3** | 早期不扰动随机初始化的投影 |
| 门控**独立学习率组**（×100） | 113 个参数不该和 8M 参数共用 lr |
| 门控**冻结 2000 步**再解冻 | 前期避免噪声梯度 |
| 正则**退火** 5e-5 → 0 | 去掉单向的"缩小残差"压力 |
| **18 个新日志列** + 每间隔一行 GATE 摘要 | 之前的 CSV 只有全局 `grad_norm`，看不出门控没学 |

### 验证结果（3000 步，解冻后仅 1000 步）

| 指标 | 旧 run（14 786 步全程） | 新 run（解冻后 1 000 步） | 倍数 |
|---|---:|---:|---:|
| 门控位移 | 9.25e−03 | **3.57e−01** | **38.6×** |
| 层间标准差 | 2.95e−05 | **1.71e−03** | **58.1×** |
| 门控梯度 | ~4e−05 | 6–40 | ~10⁵× |

**按步数归一，有效学习速度提升约 570 倍，且各层开始分化。**
