# 对象—属性绑定标注（v7，论文 4.4 节）

**对比的是**：冻结 PixArt 基线 vs 本文的**嵌入注入**配置（文本嵌入空间把对象嵌入注入相连属性token，仅颜色属性；即 §4.3.4 与图3/图4 展示的那条路线）。
两列已按行随机盲化为 **图 A / 图 B**；对照表单独存放，标注完成前不要打开。
只用颜色类 200 条：颜色过滤器只在含颜色词的提示词上生效，其余类别两侧逐位相同、标注没有信息量。

## 怎么标（推荐用网页版）

打开 **`标注页.html`**（双击即可，单文件、图片已内嵌，无需联网）：

- 每行一条提示词：**左=图A、右=图B**，右边两个下拉框分别判图 A、图 B；
- 取值三选一：

  | 取值 | 含义 |
  |---|---|
  | `proper` | 提示词中的对象都出现，且属性绑定到正确的对象 |
  | `improper` | 对象都出现，但至少一个属性绑到了错误的对象 |
  | `neglect` | 至少一个提示词中的对象没有出现 |

- 顶部显示进度；填的内容自动存在本机浏览器里，关掉再开还在；
- 全部填完后点 **「导出 CSV」**，把下载到的 `annotation_filled.csv` 发回即可。

**两名标注者请各用一份各自独立的副本**（不要在同一台电脑的同一个浏览器里填两次，
导出的文件会互相覆盖）。两人不要互相商量。

## 备选：用 CSV 填

若不方便用浏览器，可对着 `缩略图_*.jpg`（每张 25 行，左A右B，带完整提示词）
直接在 `待填_annotation_sheet.csv` 里填：单元格写 `A:proper B:improper`。

## 收齐之后（作者操作）

```bash
python3 merge_annotations.py 标注者1.csv 标注者2.csv      # 合成两列
python3 score_annotation.py annotation_sheet_filled.csv   # 三类比例 + kappa + 95%区间
```
不一致的条目先裁决（第三人判定或两人讨论），定稿后再跑一次即得最终数。
