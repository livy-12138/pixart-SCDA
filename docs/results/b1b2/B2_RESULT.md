# B2（绑定对齐损失）实测结果：无提升

**结论：B2 相对它自己的基座（gateopt）在八项中七项无显著差异，纹理显著退步。
绑定损失没有带来任何指标提升。**

训练：2026-09-19 08:05:47 → 11:52:40（14 786 步，与所有其他 run 等长）。
评测：CompBench++ 官方八项（300 prompt/类）+ 64 提示词协议 × 3 seed。

---

## 2. 训练侧证据：绑定目标没有改变门控的漂移方向

`results/_work/gate_drift_compare.py` 在相同 step 上对齐比较：

| step | 运行 | 有效强度 | drift_max | layer_std_max |
|---:|---|---:|---:|---:|
| 4000 | gateopt | 0.11147 | 0.62910 | 0.00466 |
| 4000 | **b2** | 0.11335 | 0.65300 | 0.01414 |
| 6000 | gateopt | 0.09309 | 1.02009 | 0.00871 |
| 6000 | **b2** | 0.09495 | 1.13857 | 0.03493 |
| 8000 | gateopt | 0.08194 | 1.28805 | 0.01274 |
| 8000 | **b2** | 0.08370 | 1.49630 | 0.05388 |
| 14000 | gateopt | 0.06326 | — | — |
| 14000 | **b2** | 0.06820 | — | 0.07581 |

**门控的向下漂移几乎未被改变**（0.150 → 0.068 对比 gateopt 的 → 0.063）。
在训练前就设定的判据是：若绑定损失让分支变得有用，门控应停止下滑甚至上升。
实际没有。**这个提前判据与最终评测结果一致。**

唯一的差别是 `layer_std_max`：b2 的层间分化是 gateopt 的 **4~6 倍**
（0.0758 vs 0.0351）。绑定损失确实改变了分支的内部结构，
但**没有改变它对指标的作用**。

## 3. 绑定损失本身是否在被优化

| step | bind_loss | eff |
|---:|---:|---:|
| 2000 | 1.0556 | 0.15000 |
| 4000 | 1.3088 | 0.11335 |
| 6000 | 0.8892 | 0.09495 |
| 8000 | 0.3319 | 0.08370 |
| 10000 | 0.8877 | 0.07711 |
| 12000 | 0.8325 | 0.07169 |
| 14000 | 1.0551 | 0.06820 |

**没有任何系统性下降趋势**，在 0.33~1.31 之间震荡。
即对齐目标本身也没有被有效优化——它被扩散损失的主导梯度淹没了。

## 4. 与分支效应量测量的关系（重要）

`results/branch_effect_measurement.md` 测得：**语义分支是强干预**——
关闭它会使 DiT 输出改变约输出 RMS 的 **15%**。

所以 B2 的失败**不能**解释为"分支影响力不够"。分支有充分的影响力；
问题是这股影响力没有被引导到正确方向。B2 提供了正确的引导信号，
但该信号既没有改变门控行为，也没有改善指标。

## 5. 下一个实验

`b2_frozengate`：门控**冻结**在中性强度（0.0160），整个 run 不解冻，
同时保留绑定损失。逻辑是：门控一直在向下漂移，这是优化器用"把分支关小"
来降低扩散损失的捷径；B2 未能阻止它。若门控的自由度本身让分支得以逃避，
就取消这个自由度——在固定强度下，分支必须要么对绑定有用，
要么学会产生无害输出。

与 `b2_neutral` 配对，可隔离唯一变量：**门控是否允许移动**。
配置：`configs/PixArt_xl2_coco2017_token_pair_b2_frozengate.py`
