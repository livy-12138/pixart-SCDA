# 冻结基线不一致：09-18 的基线只有颜色可用（新发现）

> 与掩码问题（ISSUE-011）、BLIP 聚合口径问题（ISSUE_BLIPVQA_AGGREGATION）都无关，
> 是独立的一条。**影响所有以 `frozen` 为对照的差值**。

---

## 1. 结论

`results/frozen/*` 的七类基线都产生于 **2026-09-18 13:11–13:33** 的同一批，
但生成条件与现在不一致：

| 类别 | 旧基线 | 同代码基线 | 是否可用 |
|---|---:|---:|---|
| 颜色 | 0.3956 | **0.3956**（逐字节相同的图）| ✅ 可用 |
| 形状 | 0.4158 | **0.4339** | ❌ 不可用，差 0.0181 |
| texture / spatial / 3d_spatial / numeracy / non_spatial | 未验证 | — | ⚠️ 不能用，须重测 |

## 2. 证据链

### 第一步：旧图与新图逐字节比对

| 类别 | 可比对 | 逐字节相同 |
|---|---:|---:|
| 颜色 | 300 | **300** |
| 形状 | 300 | **0** |

形状图不仅不同，而且差异是**实质性的**：首张不同图的最大像素差 255、
平均绝对差 **50.9**（满分 255），是完全不同的两张图，不是数值抖动。

### 第二步：排除评测器

用**当前评测器**重打分**09-18 的旧形状图**（`frozen_shape_reeval_oldimgs/`）：

| 打分对象 | 评测器 | 分数 |
|---|---|---:|
| 旧图 | 旧（09-18） | 0.4158 |
| 旧图 | **新（09-21 19:20 重跑，615 s，300 张全打分）** | **0.415809** |
| 新图 | 新 | 0.4339 |

**同样的图、不同的评测器 → 同一个分数。**所以评测器没变，差异 100% 来自图像。

### 第三步：确认同代码流水线一致

`frozen_ebcol020`（颜色过滤，对形状提示词是真无操作）与 `frozen_current` 同代码生成：

| 比对 | 结果 |
|---|---|
| 逐字节相同 | **299 / 300** |
| 分数 | 0.4338 vs 0.4339 |

约 **0.3% 的图像级不确定性**（推测为批量内核选择），对应 **~0.001 的分数噪声**。
0.4338 与 0.4339 的差异在此噪声内，无意义。

## 3. 根因（未完全确认）

生成代码本身没变（颜色 300/300 逐字节复现可证）。形状全部不同，
说明 09-18 那次**形状**的采样条件与现在不同——最可能是
**按类别的全局索引／种子派生方式**：若旧 run 在一次调用里跑多个类别，
类别在序列中的位置会改变全局索引，从而改变每图种子。
颜色是类别序列的第一个，故单跑与多跑一致；其余类别都会偏移。

生成日志已不存在，无法直接证实。**但这不影响处置方式**：
无论根因是什么，旧基线都必须按当前流水线重测。

## 4. 对已有数字的影响

用同代码基线（颜色 0.3956、形状 0.4339）重算：

| 配置 | 颜色 | 形状 |
|---|---|---|
| 不过滤属性类别（α=0.15 / 0.2） | +0.0298 ✅显著 | **−0.037**（此前按 0.4158 算为 −0.019，**低估一倍**）|
| **只改颜色词**（α=0.2） | **+0.0312** ✅显著 | **−0.0001 ≈ 0** |

**颜色的正向效应不受影响**：颜色基线与同代码逐字节一致，
+0.0298（α=0.2）与 +0.0312（只改颜色词）都是对照有效基线测得的，
配对 bootstrap 区间分别为 [+0.0029, +0.0574] 与 [+0.0041, +0.0592]。

## 5. 处置要求

1. **所有以 `frozen` 为对照的差值，若涉及形状或其餘五类，必须重测基线后再报。**
2. 基线与方法必须**同代码、同调用方式、同批次**生成。
3. 报告差值时同时给出 ~0.001 的噪声量级，不要把 0.001 级的差异当结果。
4. `results/frozen/shape` 已恢复为 09-18 原始内容；
   重评证据保存在 `results/frozen_shape_reeval_oldimgs/`。
